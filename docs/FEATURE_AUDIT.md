## 界面核对范围

- 保留原型导航、卡片、编辑器和配色；新增的是备份入口、可用性说明及真实状态绑定。
- 原型 Plus Jakarta Sans / JetBrains Mono 的相同 Web 字体随程序本地分发，附来源、SHA256 和 OFL，避免离线时因 Google Fonts 不可达改变界面。编辑器选择的其他系统字体仍需目标 Windows 安装相应字体。
- 首页、在线资源、资源库、创作中心、轮播、定时、设备、设置、插件在 720/1024/1440 像素宽度进行 27 组布局检查；1024 宽度另以 1.5 设备缩放因子模拟。
- 编辑器在同三种宽度检查保存、应用、设备预览按钮边界，并保留截图；个人中心核对演示状态。
- 浏览器缩放模拟不等于 Windows 真实 125%/150% DPI 多显示器切换；后者仍需实体环境补验。
- 独立视频目前只持续刷新选中设备的缩略预览，未选中设备保留最近采样；两台 USB 视频播放各自继续。合成场景各自更新画面，持续测试分别按视频进度和场景画面判定停滞。
- 1123 HTML 既不参与当前构建，也不发布到 GitHub。
